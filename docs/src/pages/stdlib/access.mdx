# Access control

## `Ownable`

`std/access/ownable.lithe`. One owner. Set it with `init`, usually from [`deploy`](/language/deploy), and guard owner-only entrypoints with `check_owner`.

| Function | |
| --- | --- |
| `owner() : address` | the owner |
| `check_owner()` | raises `OwnableUnauthorizedAccount` unless the caller is the owner |
| `init(initial_owner)` | sets the first owner; raises `OwnableInvalidOwner` for the zero address |
| `transfer_ownership(new_owner)` | owner only; the zero address is rejected |
| `renounce_ownership()` | owner only; leaves the contract without an owner |
| `set_owner(new_owner)` | moves ownership with no checks, for the contract's own rules |

## `Ownable2Step`

`std/access/ownable_two_step.lithe`, on top of `Ownable`. The owner proposes a new owner, who must accept. An address that can't accept, because it was mistyped, never takes ownership.

```lithe
import "std/access/ownable_two_step.lithe";

contract Vault is {
  use Ownable;
  use Ownable2Step;

  storage is record {
    limit : nat;
  }

  deploy()
    raises OwnableInvalidOwner
  is {
    Ownable.init(Evm.sender());
  }

  external view function owner is Ownable.owner;
  external view function pendingOwner is Ownable2Step.pending_owner;
  external function transferOwnership is Ownable2Step.transfer_ownership;
  external function acceptOwnership is Ownable2Step.accept_ownership;
  external function renounceOwnership is Ownable2Step.renounce_ownership;

  external function set_limit(const limit : nat)
    raises OwnableUnauthorizedAccount
  is {
    Ownable.check_owner();
    storage.limit := limit;
  }
}
```

## `AccessControl`

`std/access/access_control.lithe`. Roles, each with an admin role whose members grant and revoke it. A role is a `role`, a [nominal type](/language/types#nominal-types) over `bytes32`, so a stray hash can't be passed where a role is meant. In the ABI, a role is a `bytes32`.

```lithe
import "std/access/access_control.lithe";

contract Minter is {
  use AccessControl;

  storage is record {
    minted : map(address, nat);
  }

  (* keccak256("MINTER_ROLE") *)
  pure function minter() : role is
    role(0x9f2df0fed2c77648de5860a4cc508cd0818c85b8b8a1ab4ceeef8d981c8956a6)

  deploy() is {
    AccessControl.grant(AccessControl.default_admin_role(), Evm.sender());
  }

  external view function hasRole is AccessControl.has_role;
  external function grantRole is AccessControl.grant_role;
  external function revokeRole is AccessControl.revoke_role;
  external function renounceRole is AccessControl.renounce_role;

  external function mint(const to : address; const amount : nat)
    raises AccessControlUnauthorizedAccount
  is {
    AccessControl.check_role(minter());
    storage.minted[to] := storage.minted[to] + amount;
  }
}
```

| Function | |
| --- | --- |
| `has_role(r, account) : bool` | |
| `get_role_admin(r) : role` | the default admin role, until `set_role_admin` changes it |
| `check_role(r)`, `check_role_of(r, account)` | raise `AccessControlUnauthorizedAccount` |
| `grant_role(r, account)`, `revoke_role(r, account)` | the caller must hold `r`'s admin role |
| `renounce_role(r, confirmation)` | the caller gives up its own role; `confirmation` must be the caller |
| `grant(r, account)`, `revoke(r, account)`, `set_role_admin(r, admin)` | unchecked, for `deploy` and the contract's own rules |

## `Pausable`

`std/security/pausable.lithe`. An emergency stop. Pausing is policy, so the contract decides who may pause, and which entrypoints check `require_not_paused`.

| Function | |
| --- | --- |
| `paused() : bool` | |
| `require_not_paused()`, `require_paused()` | raise `EnforcedPause` and `ExpectedPause` |
| `pause()`, `unpause()` | no access check of their own |
