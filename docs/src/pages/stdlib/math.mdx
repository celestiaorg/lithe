# Math

Everything here is checked, like the rest of Lithe's arithmetic: a result that doesn't fit, or a division by zero, panics.

## `Math`

`std/math/math.lithe`.

| Function | |
| --- | --- |
| `min(a, b)`, `max(a, b)` | |
| `clamp(x, low, high)` | raises `MathInvalidRange` when `low > high` |
| `average(a, b)` | rounded down, without overflow in `a + b` |
| `ceil_div(a, b)` | `a / b` rounded up |
| `mul_div_up(a, b, d)` | `a * b / d` rounded up, with a 512-bit product |
| `sqrt(a)` | the integer square root, rounded down |

`a * b / d` rounded down is the built-in [`Nat.mul_div`](/language/builtins#nat-int-and-address). Its product is kept in 512 bits, so `Nat.mul_div(amount, price, 1e18)` doesn't overflow where `amount * price` would.

## `SafeCast`

`std/math/safe_cast.lithe`. Every integer conversion is checked: `nat(x)` and `uint128(x)` revert with `Panic(0x11)` when the value doesn't fit. `SafeCast.to_nat(x)` and `SafeCast.to_int(x)` check the same way but raise OpenZeppelin's `SafeCastOverflowedIntToUint` or `SafeCastOverflowedUintToInt`.

## `FixedPoint`

`std/math/fixed_point.lithe`. A `wad` is a number with 18 decimals, its own type so that a plain `nat` can't be mixed in by mistake.

```lithe
import "std/math/fixed_point.lithe";

contract Fees is {
  use FixedPoint;

  storage is record {
    rate : wad;
    fee_bps : nat;
  }

  (* 0.3% as a rate, and 25 basis points. *)
  deploy() is {
    storage.rate := wad(3_000_000_000_000_000n);
    storage.fee_bps := 25n;
  }

  external view function interest(const principal : nat) : nat is
    FixedPoint.mul_wad(principal, storage.rate)

  external view function fee(const amount : nat) : nat is
    FixedPoint.apply_bps(amount, storage.fee_bps)
}
```

| Function | |
| --- | --- |
| `one()`, `scale()` | `1e18` as a `wad`, and as a `nat` |
| `to_wad(n)`, `from_wad(x)` | whole numbers in and out, rounding down |
| `wad_mul(a, b)`, `wad_div(a, b)` | products and quotients of two `wad`s, rounding down |
| `mul_wad(amount, factor)` | an amount scaled by a `wad` |
| `apply_bps(amount, bps)` | `bps` basis points of `amount` |
