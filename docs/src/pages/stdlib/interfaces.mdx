# Interfaces

`std/interfaces` declares the common standards as [interfaces](/language/effects#interfaces), for typed `query` and `defer` against other contracts.

```lithe
import "std/interfaces/erc20.lithe";

error Too_little of nat;

storage is record {
  token : IERC20;
}

external function pay(const to : address; const amount : nat)
  raises Too_little
is {
  const balance : nat := query storage.token.balanceOf(Evm.self());
  assert(balance >= amount, Too_little(balance));
  defer storage.token.transfer(to, amount);
}
```
