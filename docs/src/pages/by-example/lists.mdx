# Lists

`list(T)` is a dynamic list and `list(T, n)` a fixed-length one. Both work in storage and in memory.

```lithe [lists.lithe]
error Out_of_range of nat;

storage is record {
  (* A dynamic list has a length. Writing at index `length` appends. *)
  items : list(nat);
  (* A fixed list has its length in its type. *)
  slots : list(address, 3);
}

external function append(const value : nat) is {
  storage.items[storage.items.length] := value;
}

external view function get(const i : nat) : nat
  raises Out_of_range
is {
  assert(i < storage.items.length, Out_of_range(i));
} with storage.items[i]

external view function length() : nat is
  storage.items.length

external function set_slot(const i : nat) is {
  storage.slots[i] := Evm.sender();
}

(* List literals build lists in memory. *)
external pure function second() : nat is {
  const primes : list(nat, 4) := [2n, 3n, 5n, 7n];
} with primes[1]

external pure function count() : nat is {
  const names : list(string) := ["a", "b", "c"];
} with names.length
```

- Append by writing at index `length`. Any other index past the end reverts with `Panic(0x32)`.
- `get` checks the bound itself, to raise a typed error instead of a panic.
- Fixed lists can be ABI parameters (`address[3]`). Dynamic lists cannot yet.
