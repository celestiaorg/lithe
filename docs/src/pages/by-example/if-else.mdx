# If / else

`if cond then { ... } else { ... }` runs one of two blocks. `if cond then a else b` chooses one of two values. There is no ternary operator.

```lithe [if-else.lithe]
(* `if` with blocks is a statement. Chain conditions with `else if`. *)

storage is record {
  size : nat;
}

external function record_size(const x : nat) is {
  if x < 10n then {
    storage.size := 1n;
  } else if x < 100n then {
    storage.size := 2n;
  } else {
    storage.size := 3n;
  }
}

(* `if` with values is an expression. Both branches are required and share a type. *)
external pure function min(const a : nat; const b : nat) : nat is
  if a < b then a else b

external pure function classify(const x : nat) : nat is {
  const size : nat := if x < 10n then 1n else if x < 100n then 2n else 3n;
} with size
```

- An `if` expression can go anywhere a value can, like a `case`: a function body, a `with` result, a `const` initializer, or an operand.
- A branch can be `fail E`, as a `case` arm can: `if amount > 0n then amount else fail Zero`.
- Inside each branch the compiler knows whether the condition held, so `if a >= b then a - b else 0n` has no underflow check.
