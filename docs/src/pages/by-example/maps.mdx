# Maps

`map(K, V)` is a Solidity mapping. It lives in storage, every key starts at zero, and keys cannot be enumerated.

```lithe [maps.lithe]
import "std/evm";

storage is record {
  balances : map(address, uint);
  (* Maps nest: owner -> spender -> amount. *)
  allowances : map(address, map(address, uint));
}

(* A missing key reads as the zero value. *)
external view function balance_of(const who : address) : uint is
  storage.balances[who]

external function set_balance(const amount : uint) is {
  storage.balances[Evm.sender()] := amount;
}

(* Deleting is writing the zero value. *)
external function clear() is {
  storage.balances[Evm.sender()] := 0;
}

external function approve(const spender : address; const amount : uint) is {
  storage.allowances[Evm.sender()][spender] := amount;
}

external view function allowance(const owner : address; const spender : address) : uint is
  storage.allowances[owner][spender]
```

- There is no `delete`. Write the zero value.
- Map keys are single words (integers, `bool`, `address`, `bytesN`, and nominal types over them), strings, or bytes. Values can be words, maps, or records of words.
